# The regular expression corpus that oracle.pl runs through Perl to write expected.txt.
#
#   P  a pattern, in the syntax of the Rust `regex` crate
#   Q  the same pattern in Perl's syntax, where the two differ (`\p{Greek}` is Script in Rust
#      and Script_Extensions in Perl; `\u{..}`, `\<` and class set operations are Rust's only)
#   R  a replacement template, expanded as the `regex` crate expands one
#   H  a haystack; `\n`, `\t` and `\x{..}` are decoded, so a haystack cannot hold a backslash
#
# Every H is run against the P above it.  A group inside a repetition keeps its capture from an
# earlier iteration in the `regex` crate (and in Python) but is reset in Perl, so no such case is
# here; tests/regex.rs checks those against Python's answers.  Nor is a repetition whose later
# iteration can match nothing, `(a*)+`, where Perl and Python report the empty last iteration and
# the crate does not; rust_suite.txt carries the crate's own cases for that.  Perl's `$` also matches before a final newline and
# Rust's does not, so no haystack under a `$` pattern ends in one; Perl's case-insensitivity
# folds `ß` to `ss` and Rust's does not, so no case-insensitive pattern meets an `ß`.
